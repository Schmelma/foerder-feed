# Förder-Calls – Feed

Automatisch erzeugter RSS-Feed mit aktuellen Förderaufrufen von Bund, NRW und EU.
Jeder Eintrag enthält Frist, Förderquote, Fördersumme, Zielgruppe und Laufzeit.

- Feed: `foerder-longlist.xml`
- Erzeugt von: RSS Scraper (lokal), wöchentlich aktualisiert

Quellen sind öffentliche Bekanntmachungsseiten; der Feed enthält keine personenbezogenen Daten.
